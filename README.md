# .github — Governança e Políticas (AM-Brasol)

Este repositório centraliza as convenções, boas práticas e documentação de referência para os projetos da
organização [AM-Brasol](https://github.com/AM-Brasol) — org operacional/legada da BRAM.

> **Estas são as mesmas convenções de [`brasol-solucoes/.github`](https://github.com/brasol-solucoes/.github)**,
> replicadas aqui para valerem também nos repositórios de `AM-Brasol`. A fonte canônica continua sendo
> `brasol-solucoes/.github` — em caso de divergência futura entre os dois, ela vence; sincronize este
> repositório manualmente quando ela mudar.
>
> Muitos repositórios pré-existentes em `AM-Brasol` antecedem esta convenção de nomenclatura (nomes sem
> prefixo de domínio, ex. `Performance`, `faturas`, `monday-api`) — isso é dívida histórica, não uma
> convenção alternativa. **Repositório novo em `AM-Brasol` segue a mesma taxonomia** desta documentação.
